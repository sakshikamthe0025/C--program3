# Addition of Two Integers in C

## Description
This C program adds two integer values and displays their sum. The values are initialized directly in the program.

## Algorithm
1. Start.
2. Initialize `iValue1` to `10`, `iValue2` to `11`, and `iResult` to `0`.
3. Add `iValue1` and `iValue2`.
4. Store the sum in `iResult`.
5. Display `iResult`.
6. Stop.

## Source File
- `program.c` — contains the C source code.

## Requirements
- A C compiler, such as GCC.
- A terminal or command prompt.

## How to Compile and Run

Compile the program:

```bash
gcc program.c -o program
```

Run on Windows:

```bash
program.exe
```

Run on Linux/macOS:

```bash
./program
```

## Expected Output

```text
21
```

## Concepts Used
- Integer variables
- Addition using the `+` operator
- `printf()` for displaying output
- `main()` function
- `return 0` to indicate successful completion

## Note
The program currently uses fixed values (`10` and `11`); it does not accept numbers from the user.
